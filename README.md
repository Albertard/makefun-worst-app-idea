# The Worst App Idea Ever Pitched

A program that writes a single sentence pitching the worst, most
useless app imaginable to `/output/entry.txt`. Built for the make.fun
competition **"The Worst App Idea Ever Pitched"**
(`u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23`).

## The pitch

> PingMe is a $4.99-a-month app that texts you the moment your fridge light turns off, so you never have to lie awake wondering whether it stays on when the door is closed — the peace of mind every modern kitchen deserves.

220 characters. The joke works through a perfect mismatch: a problem
nobody has (not knowing whether the fridge light stays on), solved
with maximum seriousness — a subscription, a push notification, and a
solemn promise of "peace of mind". The founder sounds certain, the
product sounds real, and the function is gloriously pointless: you
could answer the question by opening the door.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
